# BlancBleu — מערכת אנימציות (שלב 5)

> תנועה שמשרתת את התוכן. לא כל דבר זז, ומה שזז זז באותה שפה.

## 1. עקרונות

1. **תקציב תנועה.** בכל מסך עין אחת מובילה. ב-Hero זו הקובייה. בשאר העמוד התנועה היא חשיפה עדינה בלבד.
2. **פעם אחת.** חשיפות בגלילה מתרחשות פעם אחת ולא חוזרות כשגוללים בחזרה.
3. **קצר ועדין.** מרחק תנועה עד 32px (בדרך כלל 20px). משך אינטראקציה 300–600ms, משך חשיפה עד 900ms.
4. **רק transform ו-opacity.** שום אנימציה של גובה, רוחב או מיקום שגורמת לקפיצות בפריסה.
5. **כיבוד העדפות המשתמש.** כשהמערכת מבקשת פחות תנועה, מושבתות כל התזוזות. נשארים שינויי שקיפות וצבע.
6. **לא מעל הקפל.** אלמנט שנראה בטעינה לא מחכה לגלילה כדי להופיע. ה-Hero משתמש בכניסה ב-CSS שמתחילה מיד.

## 2. טוקנים

מוגדרים ב-`src/lib/motion.ts` (ל-JS) וב-`globals.css` (ל-CSS).

| טוקן | ערך | שימוש |
|---|---|---|
| `duration.fast` | 300ms | ריחוף, צבע, קו תחתון |
| `duration.base` | 600ms | מעברי מצב, חץ בכפתור |
| `duration.slow` | 900ms | חשיפה בגלילה |
| `ease.out` | cubic-bezier(.22, .7, .2, 1) | ברירת המחדל לכל כניסה |
| `ease.inOut` | cubic-bezier(.65, 0, .35, 1) | תנועה מחזורית |
| `distance` | 12 / 20 / 32px | מרחק כניסה (sm, md, lg) |
| `stagger` | 55 / 90 / 140ms | רווח בין אחים (tight, base, loose) |
| `viewport` | פעם אחת, 12% בתוך המסך | מתי חשיפה מתחילה |

| **כניסה בטעינה** | רק ב-Hero | CSS טהור, מתחילה לפני ה-JavaScript | כותרת מילה אחר מילה, תג, פסקה, כפתורים, קווי הקובייה |

| **תנועה סביבתית ופרלקסה** | רק אלמנט חזותי אחד במסך | Motion | קובייה (צפה, מתנדנדת, מגיבה לעכבר), `Parallax` לתמונות |

## 4. הרכיבים (`src/components/motion`)

| רכיב | מה הוא עושה | מתי להשתמש |
|---|---|---|
| `<TextReveal segments as>` | כותרת שהמילים שלה עולות ממסכה כשהיא נכנסת למסך. תומך בהדגשה בכחול | כותרות סקשן (h2, h3) |
| `<Reveal as y delay>` | בלוק יחיד עולה ומופיע | פסקאות, כפתורים, תמונות |
| `<RevealGroup as gap delay>` + `<RevealItem>` | ילדים עולים בזה אחר זה | שירותים, שלבים, שאלות נפוצות, מאמרים |
| `<Parallax speed>` | תזוזה איטית יותר מהגלילה | אלמנט חזותי אחד בסקשן. לא על טקסט |
| `<MotionProvider>` | מחיל את העדפת "פחות תנועה" על הכול | כבר עטוף ב-`RootDocument` |

```tsx
<TextReveal segments={[{ text: "למה לא הבנק" }, { text: "אנחנו מייצגים אתכם", accent: true }]} />
<Reveal as="p" delay={0.15}>הבנק מייצג את עצמו.</Reveal>

<RevealGroup as="ul">
  {items.map((item) => (
    <RevealItem as="li" key={item.id}>{item.title}</RevealItem>
  ))}
</RevealGroup>
```

## 6. מה לא עושים

- לא מוסיפים תנועה לאלמנט שכבר יש לו תנועה אחרת.
- לא מאנימציה טקסט פסקה מילה אחר מילה. רק כותרות.
- לא משתמשים ב-`Parallax` ליותר מרכיב אחד במסך.
- לא מגדירים `delay` בתוך `RevealItem`: הוא ישבור את ה-stagger של הקבוצה.
- לא מוסיפים ספריות תנועה נוספות. הכול ב-Motion ו-CSS.

## 7. מה ממומש עכשיו

- **Hero:** כניסה ב-CSS, קובייה סביבתית, סרט הנע (עוצר בריחוף, סטטי כשמבקשים פחות תנועה).
- **כותרת הניווט:** רקע וטשטוש עולים בהדרגה עם הגלילה. התפריט במובייל נפתח עם כניסה מדורגת.
- **המערכת מוכנה לסקשנים 3–9.** `Reveal` כבר פעיל בסקשן הזמני, ושאר הרכיבים נבדקו על דף בדיקה שנמחק.
